## 🏦 Bank Account Management System (Console-Based)

A simple Java console application to manage bank accounts using core **Object-Oriented Programming** principles (Encapsulation, Inheritance, Polymorphism) and structured with the **MVC architecture**.

---

### 📌 Features

- Create a new customer and account.
- Deposit, Withdraw, and Transfer money between accounts
- View account details and transactions
- All interactions via console
